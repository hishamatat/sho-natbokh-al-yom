# شو نطبخ اليوم؟

Arabic-first meal decision assistant for Arab households.  
**Decision Engine + Household Memory for Arab families.**

Permanent Web/PWA-first · Kuwait validation first · Saudi scale subject to validation.  
Planning/Validation stage — V00 preparation approved; the local validation console is ready, and no family outreach or product development has started yet.

## V00 Validation Console

لتشغيل لوحة إدارة التجربة اليدوية على Windows، افتح `افتح لوحة التجربة.cmd`. اللوحة تعمل محليًا، وتناسب الهاتف عند نشرها كرابط. تحتوي رسائل واتساب جاهزة للنسخ، وتجهّز طلبًا منظمًا لـChatGPT، وتحسب نتائج التجربة تلقائيًا من دون حفظ أسماء أو أرقام هواتف.
