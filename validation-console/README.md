# لوحة إدارة تجربة V00

لوحة محلية بسيطة تساعد مشغّلة التجربة على تسجيل العائلات والجلسات والوصفات والنتائج، وتحسب مؤشرات GO / MODIFY / STOP تلقائيًا.

## التشغيل

من مجلد المشروع، اضغطي مرتين على:

`افتح لوحة التجربة.cmd`

أو افتحي `validation-console/index.html` مباشرة بالمتصفح.

لا تحتاج اللوحة إلى تثبيت أو حساب أو اتصال بالإنترنت.

## الاستعمال من الهاتف

اللوحة جاهزة لتوضع على رابط وفتحها من الهاتف. بعد نشر الرابط:

1. افتحي الرابط من هاتف زوجتك.
2. أضيفي الرابط إلى الشاشة الرئيسية ليظهر مثل أي تطبيق.
3. استعملي هاتفًا واحدًا طوال التجربة لأن البيانات محفوظة على الجهاز نفسه.
4. نزلي نسخة احتياطية بعد كل يوم عمل.

وجود ملفات اللوحة على GitHub وحده لا يصنع رابطًا عامًا؛ يجب تفعيل نشر الصفحة مرة واحدة بعد رفع الملفات.

## أول استعمال

1. افتحي صفحة **التجهيز** وحددي تاريخ أول جلسة واسم المشغّلة.
2. افتحي صفحة **الرسائل** وانسخي إعلان المجموعة.
3. أضيفي الوصفات المراجعة. الوصفة غير المؤشرة كمراجعة لا تظهر في الجلسات.
4. عند وصول مشاركة وموافقتها، أضيفي رمزًا مثل K01 من صفحة **العائلات**.
5. افتحي **جلسة جديدة** واتبعي الأسئلة بالترتيب.
6. بعد تعبئة الإجابات يمكنك نسخ طلب جاهز إلى ChatGPT للحصول على ثلاثة اقتراحات.
7. راجعي الاقتراحات والقيود قبل إرسالها للعائلة، ثم سجلي النتيجة.
8. راجعي **الرئيسية** و**النتائج**؛ الأرقام تتحدث تلقائيًا.
9. نزلي نسخة احتياطية من صفحة التجهيز بعد كل يوم عمل.

## الخصوصية

- لا تدخلي اسمًا أو رقم هاتف أو حساب تواصل داخل اللوحة.
- احتفظي بربط الرمز بوسيلة التواصل في مكان خاص منفصل.
- لا تضعي ملف النسخة الاحتياطية داخل مجلد المشروع أو GitHub.
- لا ترسلي إلى ChatGPT اسمًا أو رقم هاتف أو أي معلومة تعرّف بالعائلة.
- عند طلب الحذف، افتحي رمز العائلة واضغطي **حذف بيانات العائلة**.

## حدود اللوحة

هذه أداة لإدارة البحث اليدوي وليست تطبيق المستخدم النهائي. الاقتراحات تختارها المشغّلة من وصفات مراجعة؛ اللوحة لا تقرر الوجبة بدلًا عنها. البيانات محفوظة في المتصفح المستخدم، لذلك النسخة الاحتياطية اليومية مهمة.
